# Logo

所有版本（根目录原版、modern、concise、contemporary）都引用 `logo.svg`，同时用作导航栏、页脚和浏览器标签图标。

换 logo：直接用新文件覆盖 `logo.svg`（保持同名），提交并推送即可。
如果新 logo 是 PNG，命名为 `logo.png`，并告诉 Claude 把各页面里的 `logo.svg` 改成 `logo.png`。

## 文件说明
- `logo.svg`：网站图标（盾牌 + 数据库锁孔 + 绿色合规对勾），用于导航栏、页脚和浏览器标签。
- `a2-synergy-full-tick.svg` / `a2-synergy-full-tick-transparent.svg`：带文字的完整标志（含合规对勾），绿底 / 透明底。
- `a2-synergy-full.svg` / `a2-synergy-full-transparent.svg` / `a2-synergy-mark.svg`：按鼠标垫原图还原的标志（无对勾）。
